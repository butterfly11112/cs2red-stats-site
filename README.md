# CS2RED Stats — сайт

Веб-версия расширения CS2RED Stats Checker: вставляешь ссылку на Steam-профиль игрока — сайт показывает его статистику с cs2red.ru (убийства, смерти, K/D, рейтинг, коины, VIP-статус, награды), плюс режим сравнения двух игроков.

В отличие от расширения, здесь всю работу делает сервер (`server.js`) — сайт можно открыть в любом браузере, ничего не устанавливая.

## Как это работает

cs2red.ru блокирует обычные запросы «в лоб» (это его защита от ботов). Сервер обходит это честно — без подделки заголовков: он запускает у себя headless-браузер (Playwright + Chromium), по-настоящему открывает страницу cs2red.ru и делает запрос уже с неё, как обычный посетитель. Так же был устроен и браузерный вариант этого инструмента.

## Проверка на своём компьютере (перед выкладыванием на хостинг)

Понадобится **Node.js** (если ещё не установлен — скачайте с [nodejs.org](https://nodejs.org/), версия LTS, обычная установка «next-next-next»).

Дальше — дважды кликните на `run-local.bat` в этой папке. Он сам поставит зависимости, скачает Chromium для Playwright (один раз, может занять минуту) и запустит сервер. Когда в окне появится `listening on port 3000`, откройте в браузере:

```
http://localhost:3000
```

Если всё работает — можно переходить к выкладыванию в интернет.

## Выкладываем в интернет (GitHub + Render)

1. **GitHub** — если аккаунта ещё нет, зарегистрируйтесь на [github.com](https://github.com/). Создайте новый пустой репозиторий (кнопка **New repository**), например `cs2red-stats-site` — **без** галочек «Add README» и подобного (файлы уже есть здесь).
2. В этой папке откройте терминал (правой кнопкой на пустом месте в папке → «Открыть в терминале», либо через меню Пуск найдите PowerShell и перейдите в папку командой `cd` до пути этой папки) и выполните по очереди:
   ```
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/cs2red-stats-site.git
   git push -u origin main
   ```
   (адрес репозитория для строки `git remote add origin` GitHub покажет сам на странице только что созданного репозитория). При `git push` откроется окно браузера с просьбой авторизоваться в GitHub — просто подтвердите.
3. **Render** — зарегистрируйтесь на [render.com](https://render.com/) (проще всего — кнопкой «Sign up with GitHub», это же свяжет аккаунты).
4. На Render нажмите **New** → **Web Service**, выберите ваш репозиторий `cs2red-stats-site`.
5. Render сам увидит `Dockerfile` и предложит собрать через Docker — оставьте как есть. Тариф выберите **Free**.
6. Нажмите **Create Web Service** и подождите первую сборку (несколько минут — Docker-образ с Chromium немаленький).
7. Когда сборка закончится, Render покажет адрес вида `https://cs2red-stats-site.onrender.com` — это и есть публичный сайт, можно скидывать ссылку кому угодно.

Важно про бесплатный тариф Render: он «засыпает» после 15 минут без запросов и следующий заход будет грузиться ~30–60 секунд, пока сервер просыпается. Для личного использования/друзей это некритично.

## Структура проекта

- `server.js` — сервер: раздаёт сайт и отвечает на `/api/profile` и `/api/compare`.
- `public/` — сама страница (HTML/CSS/JS).
- `Dockerfile` — инструкция для Render, какой образ собрать (на основе официального образа Playwright, с уже установленным Chromium).
- `run-local.bat` — быстрый запуск для проверки на своём компьютере.

Это неофициальный проект, не связан с CS2RED или Valve.
